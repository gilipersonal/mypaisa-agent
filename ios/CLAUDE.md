# ios/: the iOS app

A bare React Native 0.88 shell with a native SwiftUI core (MA-165, `ARCHITECTURE.md` §8.5). The shell owns the page and
the plumbing; every piece a member looks at is SwiftUI.

```
ios/
  package.json, src/        the TypeScript shell; it joins the pnpm workspace rooted in web/
    native/                 codegen specs, one per Fabric component
    models/                 turns data into the strings a piece draws, with the shared code in web/src/lib
    pieces/                 the shell's side of each piece: one JSON string down, its height back
    probe.ts                the shared code run on Hermes for the UI tests
  MyPaisa/                  the app target: scene delegate, launch config, icons
    Fabric/                 the Objective-C++ views and the Swift hosts
  Packages/MyPaisaUI/       the SwiftUI pieces, the bench and the design system; no React Native in it
  MyPaisaCore/              Swift that draws nothing: TestIDs
  MyPaisaTests/             what the scheme compiled in
  MyPaisaUITests/           the shell end to end, on the bundled JavaScript, under Hermes
  Config/                   Dev.xcconfig and Prod.xcconfig: bundle ids, base URLs, icons
  ReactNativeSPM/           generated by `pnpm spm`; committed, never edited
```

## Commands

The workspace root is `web/`, so pnpm runs from there, filtered to this package.

```bash
corepack pnpm@12.16.1 --dir web install
```

```bash
corepack pnpm@12.16.1 --dir web --filter @mypaisa/ios spm
```

```bash
scripts/ios_gates.sh
```

`spm` writes `build/`, which is not committed: run it once after a clean checkout. In Xcode, open `MyPaisa.xcodeproj`
and pick a scheme. **MyPaisa Dev** runs Debug through Metro against dev; its tests use the `Dev` configuration, which is
optimised and bundles its JavaScript. **MyPaisa** is prod, `Release`.

On the local stack: `scripts/local/README.md`.

## The rules

1. **No CocoaPods, ever** (MA-229). `Podfile` is one comment because the React Native CLI finds an iOS project only
   through that file. A native library that cannot build with Swift Package Manager is replaced.
2. **The shell formats; a piece only draws.** Nothing in Swift formats a figure.
3. **A new piece copies the hero:** its spec in `src/native`, its model in `src/models`, its wrapper in `src/pieces`, its
   SwiftUI in `Packages/MyPaisaUI`, its host and `.mm` in `MyPaisa/Fabric`, its snapshot test, and its bench.
4. **Interactive cards and charts use `.accessibilityElement(children: .contain)`, never `.combine`;** every selector is
   in `web/src/lib/test-ids.ts` and `MyPaisaCore/Testing/TestIDs.swift`.
5. **Shared code from `web/src/lib` runs on Hermes, so check it there.** Jest and vitest run Node; only the app runs
   Hermes. `Intl` threw at launch on `signDisplay: 'negative'` (MA-165), so `money.ts` uses none. New shared code that
   depends on the runtime goes in `src/probe.ts`, and `ShellUITests` reads the result.
6. **A shared file imports no door's framework** (lesson 48): `@tanstack/query-core`, never `svelte-query` or
   `react-query`.
7. **`MYPAISA_*` hooks live under `#if DEBUG`, probes under `MP_PROBES`,** and the local journey under `__DEV__`. The gate
   fails if any of them reaches `Release`.
8. **`hermes-compiler` is pinned to the version `react-native` names.** Move it with every React Native upgrade: a
   mismatch crashes at launch with a bytecode error, and the gate fails on two versions. Dependabot never moves it on
   its own (PR #113, MA-344), so a Dependabot PR that raises `react-native` fails the gate until it is pinned by hand.
9. **Colours come from `tokens.css`** through `scripts/ios_tokens.py`. `Colors.xcassets` and `MPColor.swift` are
   generated, never edited.
10. **Babel stays on 7 until React Native moves.** Babel 8 stops the bundle at its first file while Jest and tsc pass, so
    the gate bundles the app with Metro, on CI's Linux job too, and Dependabot skips Babel majors (PR #96, MA-327).

Liquid Glass goes on controls only, and carries labels only; the hero is content, so it is never glass.
