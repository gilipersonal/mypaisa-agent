## Gotchas that cost time this session

1. **The board gates are slow and fight each other for CPU.** Running two or more Playwright jobs together turned 10-minute runs into 25-minute ones and caused `exit 142` (alarm) timeouts with no real fault. Run them alone or split by engine, with generous alarms:
   - `node scripts/board_fit.js --engine chromium --jobs 4` and the same with `webkit`: about 12 minutes each, run in parallel without anything else.
   - `node scripts/board_fit.js --diff origin/main --expect review/<story>/drawn-changes.json`: do **not** run it for both engines in one process. `Prototype v4.dc.html` alone is 264 steps per engine. Use `--only "^(?!app-v1/Prototype v4\.dc\.html$)"` per engine, and the Prototype v4 board on its own.
   - `--selftest` takes about 8 minutes when nothing else runs.
2. **`python3 scripts/review_regress.py MA-240` takes over 50 minutes serially** (58 Playwright checks) and hit a 3000s alarm. I ran its checks through `review_regress.run_check` in 4 worker threads instead. The helper is `/Users/arundutta/.gemini/antigravity/brain/1b17f652-1ada-4d20-a57c-fb28b975f77f/scratch/regress_parallel.py` (`python3 regress_parallel.py MA-240 4`): about 20 minutes, amended checks first, exits 1 on any failure. The repo's own runner has no subset or parallel option, so consider adding one.
3. **A ledger check can pass or fail because a board changed, not because the guard broke.** After the board swap, two MA-240 checks (`r2-23` week chips, `r2-37` Proof note over the axis) failed because their mutation no longer bit on the new Forecast card. The probe script `scratch/probe.sh` mutates a copy of `docs/design`, runs the gate, and prints rows. Re-aiming the mutation (14px chip columns; removing the note width rule) restored the refusal. Both carry an `amended` note. This is worth a lesson in `.claude/rules/independent-review.md` (Lesson 40's neighbour): a mutation check must be re-proven against the boards as they now are, and a ledger run needs a parallel runner. I did not edit `.claude/rules/`.
4. **`confluence_docs.py write` must run before `plan_sync.py selftest`** when boards or the trace change, or two mutated-record checks fail on stale pages.
5. **Shell `$` in ledger checks:** inside `python3 -c "..."`, `$200` expands. Use `chr(36)`.
6. **`capture_boards_ephemeral.js` takes the repo root (`.`)**, not `docs/design`.
7. `gh pr create` fails if a PR for the branch already exists (it did, #76); use `gh pr edit`.
8. Jira transition ids in this project: `31` In Review, `41` Done. `transitionJiraIssue` wants `transitionId` (or `transitionName`), not `transition: {id}`. cloudId `81c51173-bbea-4905-bbc5-1a880fa348bb`.
