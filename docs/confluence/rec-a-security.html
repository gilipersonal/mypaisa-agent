14. Security and privacy

As v1 (no keys, IAM in Terraform, OIDC pinned to this repository's ids, dedupe, untrusted text), plus: every file a member sends is kept for good in a private, encrypted bucket and opens only through five-minute links after a role check (§4.6, MA-148, MA-149); extracted figures carry their source line, and extracted records never keep a PAN, an address or an account number; a protected PDF's password is never stored; privacy mode hides pounds in every card, every screen and every notification.

Untrusted text is no longer only the web's: every third-party text, a file's included, reaches a model only as labelled data, files are read by a quarantined extractor with no tools, and a conversation that has read such text, with every note and summary drawn from it, loses every tool that sends data out; a red-team suite proves it on every change (§23.2, §23.3). The doors render a reply as plain text and card fields, with no remote image and no link the reply invents.

The web app keeps v2's browser rules (§9.4): the session cookie is HttpOnly, Secure, SameSite=Strict, set by the api for its own host; CORS admits only that environment's dashboard; responses carry a strict Content-Security-Policy, with SvelteKit's script hashes; the service worker caches the shell only. The cookie is never widened to .mypaisapp.com while the apex still serves the old tracker (until the cutover of phase 9, §12). The stream on the api host re-checks the member's status and session epoch every 60 seconds, so a sign-out or a pause ends an open stream at once (§21.5, MA-102). The Web Push key (VAPID) is a write-only SSM parameter like every secret: Terraform makes it with a placeholder, and Arun puts the value by hand after the apply (.claude/rules/aws-changes.md).

The correction route takes only the fields a kind marks editable, only on records the member may correct (their own; the owner, anyone's), and only through the write service, which validates and audits it (§4.10); plan items and saved assumptions only from the admin.

The iOS app adds: identity is Cognito's, one pool per environment (§4.5). Apple's and Google's identity tokens are verified in Cognito's custom-auth Lambdas against the providers' published keys (issuer, audience, expiry, an issue time under five minutes, the api's one-time nonce, replay refused) and mapped to a member through the sub linked to their Cognito user, never by address; passkeys are WebAuthn, checked in the same custom auth, with the environment's dashboard domain as the relying-party id, fixed before anyone registers (§4.5). Tokens live in the Keychain, this device only; access tokens last five minutes; refresh tokens rotate; the api's authorizer checks the token, the member's status and session epoch on every call and when a stream opens, and the stream again every 60 seconds; tokens from one environment are refused by the other. The second check is a fresh, server-verified Sign in with Apple, passkey or Google assertion bound to the action (§4.5, MA-76); a local Face ID never authorises anything on the server. The app pins no certificates but trusts only HTTPS (App Transport Security), keeps its offline copy under complete file protection, hides its snapshot in the app switcher, and shows no amount in a notification unless the member asks. Push payloads carry no figures the lock screen would show. The audit log is append-only and hash-chained.

The two environments share one AWS account and are kept apart by IAM: every Lambda role reaches only its own environment's resources; the developer's role works in dev and an explicit deny keeps it out of anything tagged env=prod; prod changes only through CI from main, after approval (§18). An optional seven-layer AWS VPC enterprise lockdown and three-way aws:SourceVpce Data Perimeter across dev and prod (MA-283, MA-284; docs/RESEARCH.md §9) is designed and costed across five options — Option 3 (Lean Zero-Trust VPC: +£13.32/month in 3A, or +£24.86/month in preferred 3B with CloudFront Pro bundled AWS WAF on prod, both inside §15.2's £50/month AWS cap) preferred over Option 2A/2B (£149.01 / £70.39/month) and Option 1 (£729.91/month) — and is decided last, after Phase 20 (enable_vpc_lockdown = false by default). Secret values live only in SSM, set by hand; Terraform creates the parameters with a write-only placeholder (value_wo), so no secret ever reaches its state: with value, the AWS provider would store the decrypted value on every refresh, whatever ignore_changes says (MA-159). Each member should keep two-factor authentication on their Apple Account and Google account and a passcode with Face ID on each device (MA-72), since that account and that device are now the key to the app.
