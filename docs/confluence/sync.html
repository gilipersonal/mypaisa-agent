🔁 What keeps them the same

  • One source each. Estimates and dates live in docs/roadmap.json; stories, boards and code paths in docs/trace.json; the words in PLAN.md and ARCHITECTURE.md. Every page here is generated from them.
  • The check. python3 scripts/plan_sync.py check runs on every PR and in CI. It fails when a page in docs/confluence/ is stale or unpublished, a board preview is older than its board, the roadmap or PLAN's Timeline is stale, a board or a section a story cites is missing, or a story In Review or Done names no code, or code that does not exist.
  • The live side. /plan-sync compares each page's version here, each epic's due date and every story's key, epic, labels and status in Jira, and fixes or files what differs.
  • The receipt (MA-303). A page sent by hand can arrive cut short (MA-300), so each page is read back from Confluence once it is published and compared with the file sent: python3 scripts/confluence_docs.py set-readback records the receipt, and the check fails while a page published is not read back, or as read back differs from what was published.
  • The designs, in the repo (MA-260). Arun, 30 Oct 2026: "for all future design use Local folder and then Claude Artifact. Claude Design is going away, so no need to push to claude design". The boards are drawn and edited in docs/design/, and nothing is read from or written to Claude Design again. Git is the boards' only record (MA-296: "I dont need claude-design sync anymore"): there is no record file to update and no whole-set Artifact to republish; python3 scripts/plan_sync.py check reads each board a trace row cites for its canvas titles only. Each design round's options are published as a private Claude Artifact for Arun to look at, comment on and pick from; a round run in Google Antigravity, which cannot publish one, shows the same page locally (MA-297). Until 30 Oct 2026 the boards were drawn in standalone Claude Design, which closes by 14 Dec 2026, and copied in (MA-259); the choice is recorded in docs/design/reviews/MA-259/decision.md.
  • The hooks, in this repo only. After an edit to a record, the check runs and reports drift at once. Raising a PR with drift is refused. When a new design or feature is discussed, the session is reminded to file its Jira issue and its Confluence page in the same change.

🆕 New work

A new design or feature gets, in the same change: its Jira story or task under its phase epic, its PLAN.md bullet, its trace row and its estimate in docs/roadmap.json, and its place on its phase page here. A new phase gets its epic, its PLAN section and its own page. Boards come before code (/design-first), and the picked boards are the spec.
