The maths, ported from the desk and extended. The PriceSource contract (MA-41) and the minimal yfinance pricing (MA-207) landed in phase 5, so the holdings are already valued every day; this phase completes the chains (MA-42) and builds the engine on them.

  • Price source chain: yfinance (0P…L ids for the funds, tickers for ETFs), BlackRock product page, FT tearsheet; Twelve Data for the US lines; ECB FX and calendars from phase 3 (MA-44). EODHD is not in the chain unless this phase shows the free sources missing or misreporting London closes.
  • The source-comparison report: when two plugins are configured for an instrument, both are recorded and the Activity page lists disagreements; run yfinance against EODHD's free trial for the first month and decide from the numbers. Verify which source actually serves the Monzo funds' NAV, and record the answer in docs/RESEARCH.md. yfinance is unofficial and can break without notice, so the ingest job treats a failed or stale source as a normal day: it falls through the chain, marks the valuation provisional, and the 07:45 alarm fires only when every source has failed for two days.
  • Proxy basket from the factsheet's top holdings; proxy-vs-NAV gap.
  • Input hygiene: interpolated bars, provisional closes, STALE exclusion.
  • indicators: the desk's stack ported to pandas, plus ATR, realised vol and percentile, drawdown, 12-1 momentum. Golden tests from the desk's self-tests (constant-series EMA, monotonic RSI, MACD = EMA12 − EMA26, flat %B) and from hand-checked fixtures.
  • pillars: Trend, Momentum, Risk; flags; the holder's cascade; confidence v0 (agreement + persistence + quality, no history yet).
  • macro: the desk's US basket ported; UK and EU baskets defined; per-instrument macro from look-through weights.
  • Forecast ranges by block bootstrap.
  • ingest and engine Lambdas on the 07:00 / 21:00 schedule; Signals and Stances written daily (stances in shadow).

Tests: the plugin contract suite, run against every plugin on recorded responses (same Bars shape, pounds not pence, the stale rule, idempotence per date, a clean failure when the vendor is down), with the recordings refreshed only by a deliberate command; golden files for every indicator and pillar; property test that local + FX = total; cascade cases for each action; macro regime cases from the desk's synthetic generator; self-test gate.

Exit: five trading days of signals landing by 07:10 that match a manual spot check; the desk's own test cases pass on the port.

Cost: £0.10 (£20 more with EODHD Historian).
