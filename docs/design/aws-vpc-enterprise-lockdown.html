1 · Layers 1 & 2 — Dual-stack VPC topology, subnet tiers & front-door ingress (MA-283, MA-284)

Zero public compute, zero dev↔prod peering, and two front-door patterns (CloudFront VPC Origin vs edge mTLS)

Every part of MyPaisa sits behind CloudFront's front door with zero public servers. Inside each environment's private network, functions that only calculate numbers or read uploaded PDFs sit in a sealed room with no internet wire at all, while functions that talk to Claude or Apple sit in a one-way room that can call out to approved domains but can never be called directly from the internet.

  • Non-overlapping dual-stack VPCs + VPC Block Public Access ($0/mo): mypaisa-dev-vpc (10.10.0.0/16, 1–2 AZs) and mypaisa-prod-vpc (10.20.0.0/16, 2 AZs, us-east-1a/b) + AWS IPv6 /56, zero VPC peering, default VPCs deleted region-wide, and declarative VPC Block Public Access (BPA) preventing accidental public ingress routes.
  • Three subnet classes per AZ: Isolated (zero 0.0.0.0/0 or ::/0 route: rules engine, projection, DB workers, quarantined PDF/file extractor), Private Egress (api, stream, agent, auth, ingester, notifier, private arm64 CodeBuild), and Perimeter (NAT / TLS-SNI proxy only; zero app compute).
  • Front-door API & SSE rule: CloudFront VPC Origins ($0 extra fee) targets Internal ALB/NLB/EC2—not Private API Gateway (execute-api VPCE). Option 1 uses Pattern A (CloudFront -> VPC Origin -> Internal ALB -> Lambda, $35.19/mo for 2 ALBs); Preferred Option 3 uses Pattern B (CloudFront Pro WAF -> Regional API Gateway REST API with disable_execute_api_endpoint = true and mTLS/origin-secret lock at $0/mo ALB cost).
2 · Layer 3 — Free Gateway Endpoints, three-way Data Perimeter & presigned S3 carve-out (MA-283, MA-31, MA-111, MA-149)

Stolen IAM keys fail outside the VPC, inside code cannot exfiltrate to foreign S3, and 5-minute file links still work

Amazon gives S3 and DynamoDB private back-door wires inside a VPC completely free. By locking our buckets and tables to those private wires, even if a temporary AWS key leaked onto the internet, an attacker could not read a single row—while a tight 15-minute exception lets your iPhone or laptop upload a statement or preview an Audit PDF safely.

  • Three-Way AWS Data Perimeter ($0.00/mo): (1) Network Perimeter (aws:SourceVpce explicit Deny on S3, DynamoDB, KMS and SQS outside the environment's VPCE); (2) Resource Perimeter (aws:ResourceAccount = "545595341442" on Gateway Endpoint policies so compromised packages inside the VPC cannot push data to an external S3 bucket); and (3) Identity Perimeter (aws:PrincipalAccount = "545595341442" on VPCEs).
  • Gateway Endpoints ($0) vs Interface PrivateLink ($7.30/AZ-mo): Every option turns on free S3 and DynamoDB Gateway Endpoints. Option 1 adds 26 PrivateLink AZ-endpoints ($189.85/mo); Option 3 keeps low-volume SigV4 TLS 1.3 control calls (ssm, kms, sqs, xray, cognito-idp) over the allowlisted NAT/SNI proxy, saving £146.04/month.
  • Presigned S3 & 5-minute Audit preview join (ARCHITECTURE §4.6, §18.5): Member browsers/iPhones and MA-111's 15-minute laptop .xlsx link hit S3 from client IPs, not aws:SourceVpce. We preserve them via CloudFront Signed URLs over OAC (aws:SourceArn) or a surgical mypaisa-<env>-presigner role carve-out bounded by s3:signatureAge <= 900000 (15 minutes).
3 · Layers 4, 5, 6 & 7 — Walled-garden DNS + TLS-SNI egress, private CI & four serverless VPC gotchas (MA-283, MA-232, MA-237)

Default-deny outbound filtering without $288/AZ Network Firewalls, and every Lambda VPC trap handled up front

Even functions allowed to call the outside world can only reach our exact list of approved partners (Claude, Apple, Google, market feeds). Any surprise domain lookup is blocked and triggers an instant security alert, and raw IP connections trying to sneak past DNS are dropped at the TLS handshake.

  • Route 53 Resolver DNS Firewall (~$0.20/mo) + Graviton t4g.nano TLS-SNI Proxy ($7.36/mo/env): Security Group sg-lambda-egress permits outbound TCP 443 only (dropping port 53/853 DNS bypass). DNS Firewall allows the exact runtime & CI domain lists and blocks * (NXDOMAIN + CloudWatch/SNS canary alarm). In Preferred Option 3, free IPv6 EIGW + an auto-healing Graviton t4g.nano (fck-nat + Envoy transparent TLS ClientHello SNI filter, $3.07 EC2 + $3.65 EIP + $0.64 gp3 = £5.66/mo/env) stops raw-IP bypasses without paying $584/mo for AWS Network Firewall (trading instant AZ NAT failover for ~60–90s ASG self-heal while SQS FIFO holds messages).
  • Private CI/CD, zero bastions & telemetry: Existing arm64 CodeBuild (MA-237) attaches to Private Egress subnets; zero SSH port 22 anywhere (SSM Session Manager only); v5 VPC Flow Logs + DNS Block Logs stream directly to KMS-encrypted S3 ($0.25/GB) alongside GuardDuty (~$2.41/mo) and CI VPC Reachability Analyzer ($0.10/check on infra/ network diffs).
  • Four serverless VPC gotchas solved: (1) Hyperplane ENIs shared across 2 tier SGs (2–4 ENIs/VPC); (2) In-image ADOT collector needs xray.us-east-1.amazonaws.com:443 egress unlike free Lambda stdout logs; (3) Cognito cognito-idp PrivateLink covers SDK/custom-auth while triggers cache Apple/Google OIDC JWKS over allowlisted 443; (4) Presigned S3 links use OAC / bounded presigner carve-out (§2).
4 · Five-option us-east-1 costing ($1.30 = £1.00, 730 hrs/mo) & five-step zero-lockout rollout (MA-283, MA-284)

Option 3 captures the highest-leverage zero-trust controls for +£13.32 to +£24.86/month—comfortably inside the £50/month AWS cap

Full bank-grade AWS appliances (Network Firewalls, Transit Gateways and 26 PrivateLink endpoints) cost £730 a month because they charge hourly fees meant for big banks with dozens of accounts. Option 3 (Preferred) uses every free AWS Data Perimeter lock plus lightweight Graviton egress proxies and CloudFront's flat-rate WAF, adding just £13.32/month (3A) or £24.86/month (3B with full prod WAF)—keeping total MyPaisa AWS spend well under our £50/month ceiling. We decide whether to switch it on last, after Phase 20.

  • Why Option 3 is Preferred: Option 1 (£729.91/mo) and Option 2A/2B (£149.01 / £70.39/mo) breach §15.2's £50/month AWS cap due to fixed hourly charges ($288.35/AZ Network Firewall, $36.50/mo Managed NAT GW incl. $3.65 EIP, $7.30/AZ-mo Interface VPCEs). Option 3A (+£13.32/mo = +$17.32/mo) and Preferred Option 3B (+£24.86/mo = +$32.32/mo, adding CloudFront Pro's bundled AWS WAF + Bot + DDoS on prod with zero overages) keep total MyPaisa AWS spend at £16.82/mo or £28.36/mo.
  • Safe five-step zero-lockout rollout (when opted into after Phase 20): Step 1 applies VPCs, BPA, free S3/DDB Gateway Endpoints and DNS Firewall in ALERT mode; Step 2 brings up EIGW + t4g.nano SNI proxy and moves CodeBuild inside the VPC; Step 3 attaches Lambdas by tier and verifies smoke.py --env dev + ADOT X-Ray traces; Step 4 locks API Gateway mTLS + CloudFront Pro WAF and flips DNS Firewall * to BLOCK; Step 5 enforces aws:SourceVpce Deny policies and CI VPC Reachability Analyzer checks.
