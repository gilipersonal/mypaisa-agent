1 · Delivery pipeline (MA-25, MA-107, MA-237, MA-268)

Build once on AWS CodeBuild arm64, prove in dev, promote the exact digest to prod

Every change starts on a pull request where automated checks test the code, the screens, and the security rules. Once merged to main, AWS builds the container image once, deploys it to the test environment (dev), and runs a full rehearsal.

Production (prod) never rebuilds code and never moves without your click. After you approve in GitHub, the exact same verified image is switched on behind a live pointer, checked in seconds, and rolled back automatically if anything looks wrong.

  • PR Gates (.github/workflows/pr-gates.yml): Runs on ubuntu-24.04-arm (1x) for L1–L3 regression, OpenAPI contract parity, 7-layer security scans, T0 agent replays, and terraform plan via OIDC role ci-plan. Path-filters Playwright (web/**, cards/**) and macOS XCUITest (ios/**).
  • Build Once on AWS CodeBuild Arm64 (MA-237): On merge to main, GitHub Actions triggers CodeBuild arm1.small (within the 100 free mins/mo). CodeBuild builds the multi-stage Dockerfile targets (lambda and stream), runs trivy image --exit-code 1 --severity HIGH,CRITICAL, and pushes to the single mypaisa ECR repository, returning immutable sha256 digests.
  • Dev Auto-Deploy & Prod Promotion (MA-107, MA-268): Terraform applies infra/dev with the new digests, runs scripts/smoke.py --env dev, and pauses at the GitHub prod environment gate. After your approval, infra/prod applies the identical ECR digests, flips each Lambda's :live alias, runs scripts/smoke.py --env prod, and only then syncs S3/CloudFront and promotes TestFlight.
2 · Seven-layer vulnerability gate (MA-267)

Every secret, source file, dependency, Terraform resource, container image and live route is scanned

Security checks run automatically before code can merge, when container images are built on AWS, after deployment, and every Monday morning at 04:00 UTC so newly discovered vulnerabilities in third-party libraries are caught even during quiet weeks.

  • Shift-left to post-deploy (scripts/security_scan.py): Combines gitleaks (Gate 1), ruff Bandit S + semgrep + eslint-plugin-security (Gate 2), pip-audit + pnpm audit + trivy fs on ios/Package.resolved (Gate 3), tflint + trivy config + the value_wo SSM rule (Gate 4), trivy image + ECR Basic Scan on push (Gate 5), Inspect AI T0 prompt-taint & OTel PII-leak checks (Gate 6), and live TLS/CSP/401 perimeter checks + Monday 04:00 UTC scheduled sweeps (Gate 7).
3 · Smoke suite & prod read-only safety (MA-268, MA-232)

Full synthetic round-trip and X-Ray trace in dev; strictly read-only canary and <5s rollback in prod

In dev, the smoke runner signs in as a synthetic member, opens the live stream, sends a test message, and checks that the entire trace shows up in AWS X-Ray. In prod, where only your real family data lives, the smoke runner never writes a single row—it verifies health, encryption, security headers, and the authentication perimeter, and instantly rewinds the release if any check fails.

  • scripts/smoke.py --env dev --up-to-phase N: Verifies /v1/health SHA parity, /v1/health?deep=1, OpenAPI 401 perimeter, synthetic Cognito sign-in, /v1/stream SSE handshake, scripted chat turn, RunRecord, and polls aws xray batch-get-traces to assert one unbroken trace across api $\rightarrow$ SQS $\rightarrow$ agent $\rightarrow$ sender.
  • scripts/smoke.py --env prod --up-to-phase N: Honours .claude/rules/aws-changes.md (zero script writes to prod): verifies /v1/health, read-only /v1/health?deep=1 (DescribeTable, HeadBucket, GetQueueAttributes, KMS), CloudFront HSTS/CSP & Universal Links, OpenAPI unauthenticated 401 guard, and zero CloudWatch error alarms.
4 · Five-layer regression pyramid & runner cost analysis (MA-269, MA-272)

Five testing layers across Phases 0–20 at £0.00/month by defeating the 10x macOS multiplier

GitHub charges ten minutes of quota for every one minute on a Mac runner, so running iPhone simulator tests on every commit would burn through the free monthly allowance in twenty runs. By running Python, web, and iOS TypeScript tests on fast Linux arm64 runners, building Docker images on AWS CodeBuild's free tier, and running Xcode Simulator tests only when iOS files change, the entire regression suite runs for £0.00/month.

  • Five-Layer Pyramid (scripts/regression.py): L1 Unit + Hypothesis + openapi-typescript zero-diff (~20s); L2 moto + FastAPI ASGI multi-Lambda integration (~30s); L3 Inspect AI T0 deterministic replay + 646 wealth-tracker & 11 trading-desk golden maths fixtures + PII leak check (~45s); L4 Path-filtered Playwright (390/1440, light/dark, axe-core) & iOS XCUITest/Snapshot/AX5; L5 Change-gated live T1/T2 evals.
  • Option D Hybrid Runner Math: ~450 Linux mins/mo (1x) + ~80–120 path-gated macOS mins/mo (800–1,200 billed at 10x, or 0 on self-hosted Mac) = 450–1,650 billed GitHub mins/mo (< 2,000 free tier) and ~63 CodeBuild arm64 mins/mo (< 100 free tier) = £0.00/month.
